# renamer

A bulk file renamer for the terminal. Preview by default. Pass `--apply` to actually rename. Every rename is undoable.

## Download

[Latest release](https://github.com/Nixon612/renamer/releases/latest) — download `renamer.py` and run it. No installation needed.


py renamer.py folder --replace " " "" # preview
py renamer.py folder --replace " " "" --apply # rename
py renamer.py undo # undo last rename


Python 3.8+, no dependencies
